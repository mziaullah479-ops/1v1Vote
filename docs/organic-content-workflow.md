# Organic Content Workflow

The weekly GitHub Actions workflow reads the public RSS feed and creates a small set of profile-discovery drafts with UTM-tagged links. The output is uploaded as a short-lived artifact for manual review.

The workflow does not create accounts, buy links, send spam, generate fake visits, or publish automatically. Before sharing, the owner should check that each profile is accurate, the wording is useful, and the destination is relevant to the audience of the selected platform.

Recommended distribution:

- Share a small number of genuinely useful profile or ranking explainers in relevant communities.
- Prefer original commentary, source links, and transparent disclosure that the destination is 1v1Vote.
- Use the profile URL with the included UTM parameters so GA4 can separate organic referrals by campaign.
- Remove a draft if the source profile changed or the post would look repetitive.
- Use platform-native tools and follow each platform's community and automation rules.
